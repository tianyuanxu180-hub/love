## 引用格式

按常见毕业论文的GB/T 7714顺序编码制著录结构统一为：

`[序号] 作者. 题名[J]. 期刊, 年, 卷(期): 文章号. DOI: ...`

英文作者姓氏大写、名字用缩写，列前三名作者后加`et al.`。两张TT/Np-TPDA-COF案例出自同一篇论文，统一使用[1]。图号和裁剪信息另行说明，不混作论文题录。2506111、3434、2671均为文章号。

## 已落实的修改

1. 原来的“Xu et al., Adv. Funct. Mater. ...”简写改成包含作者、完整题名、文献类型[J]、完整期刊名、年卷期、文章号及DOI的著录条目。
2. 同一论文复用同一编号，TT/Np两个案例共用[1]，UiO-66使用[2]，ACOF-1使用[3]。
3. UiO-66区分“图2(b)的PXRD曲线”和“图2(c)的TEM粒径”，避免读者以为粒径直接由所展示的PXRD图得到。
4. Nature Communications的两张裁剪图保留裁剪说明和CC BY 4.0信息，完整许可链接保留于对应页备注。
5. 原模板、页面主体、科学图像、字号和配色沿用此前版本，仅调整文献页脚的文字和占位高度。讲稿备注中补充了原文链接及相关证据的图号。

## 科学表述核对

- UiO-66：峰展宽与有序区域尺寸减小相一致，但峰宽还可能受微应变、缺陷和仪器等因素影响。不能单凭宽峰认定样品完全无定形，也不应将TEM粒径直接等同于XRD相干衍射畴尺寸。
- ACOF-1：正文给出的约2.5°、4.2°、4.9°、6.5°、8.4°依次对应(100)、(110)、(200)、(210)、(310)。正文拟合指标为Rp=3.89%、Rwp=5.71%。
- ACOF-1：SAXS辅助证据见Fig. 2f–g，HRTEM见Fig. 2h。Pawley拟合良好支持晶胞及峰位匹配，但不能单独证明原子结构模型唯一。保留此前页面对此的限定表述。
- TT/Np：页上Rp/Rwp值目前只能确认来自用户提供的图像，未取得原始论文图像独立核对，因此不将它们列为已核验的原文数值。

# 面向果蔬与食品保鲜的机械抗菌研究框架

本目录包含参照“有机/聚合物光伏-逻辑图”样式优化的横向逻辑图，以及食品保鲜场景的研究定位、关键科学问题、优先阅读文献、候选课题方向和一周入门路线。

## 逻辑图

![食品保鲜用机械抗菌逻辑图](mechanobactericidal_food_logic.svg)

## 研究主线

材料与表面结构 → 物理过程与细菌响应 → 微生物控制 → 食品品质与货架期。

## 候选课题

1. 湿态稳定的机械抗菌包装表面。
2. 食品组分覆盖对机械抗菌的影响。
3. 包装接触方式与真实果蔬保鲜效果的关联。

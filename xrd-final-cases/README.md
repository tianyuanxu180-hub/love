## 四个案例页的逻辑

- 第7页 TT-TPDA-COF：先看低角峰位，再看Pawley全谱拟合，最后说明候选晶胞与图谱相容，以及AA堆积仍需其他表征判断。
- 第8页 Np-TPDA-COF：先检查主峰和弱峰，再比较拟合结果，最后说明候选晶胞能够解释图谱，性能差异需结合电化学测试。
- 第9页 UiO-66：先确认峰位是否保留，再观察峰宽和峰重叠，最后说明峰展宽与有序衍射区域减小相一致，并区分TEM颗粒尺寸和XRD晶畴信息。
- 第10页 ACOF-1：先标出峰位和晶面，再看拟合并结合散射、HRTEM等证据，最后说明反平行AA堆积得到多种证据支持，但模型并非由单一拟合唯一确定。
